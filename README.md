# eSignature — legal & support pages

Static GitHub Pages site for eSign Fill & Sign PDF Document ("eSignature" on the home screen; iOS, bundle `pdfsignature.electronic.doc.com`, App Store id 6744109118), published by Zintex OÜ.

- `index.html` — support page + FAQ (use as **Support URL**)
- `privacy.html` — privacy policy (use as **Privacy Policy URL**)
- `terms.html` — terms of use (linked from the app's paywall/settings and from the signing page)

Enable Pages: repo **Settings → Pages → Deploy from branch → main / (root)**.
